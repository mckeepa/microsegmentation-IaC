# Historical Source Material

These files preserve the original proposals, examples, and diagrams. They are not current setup instructions. Some contain incomplete/escaped code, unpinned installers, unimplemented file layouts, and assumptions about policy equivalence or interface binding that the current design does not accept as proven.

Do not run deployment commands from this directory. Start with the [current checkpoint](../IMPLEMENTATION-STATUS.md) and [task guides](../../scripts/README.md). For reviewed design boundaries, see the [current architecture](../ARCHITECTURE.md).

The duplicate diagram files are retained as source history. The original unqualified feasibility-analysis file was empty; the updated analysis contains the source text. The directory name `orginal` is retained to preserve existing paths.
